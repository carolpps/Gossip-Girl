
# Gossip Girl

Um site inspirado no universo de *Gossip Girl*, desenvolvido como projeto para praticar HTML, CSS e JavaScript.

## Sobre o projeto

O site apresenta um espaço inspirado no blog de fofocas da série, com uma interface baseada em sua estética e navegação.

## Funcionalidades

- Navegação entre as páginas Home, Posts, Fotos, Links e Enviar fofoca
- Formulário para enviar uma fofoca com título e texto
- Armazenamento das fofocas no navegador usando `localStorage`
- Tradução de textos fixos entre português, inglês e espanhol

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

## Observação

As fofocas enviadas ficam salvas apenas no navegador em que foram enviadas. O projeto é uma criação independente, feita para fins de estudo, e não é afiliado à série de livros e televisão *Gossip Girl*.
