

# 💋 Gossip Girl
### *You know you love me. XOXO.*

Um projeto inspirado no universo de *Gossip Girl*, criado para explorar HTML, CSS e JavaScript — com fofocas, segredos e um toque de Upper East Side.

---

## Sobre o projeto

Bem-vindo ao mundo de *Gossip Girl*, onde todo mundo tem algo a esconder e nenhuma fofoca passa despercebida.

Este site recria a atmosfera do famoso blog da série, com uma interface inspirada em sua estética e navegação. Um pequeno espaço para praticar desenvolvimento web… e espalhar alguns segredos.

## Funcionalidades

- Navegação entre Home, Posts, Fotos, Links e Enviar fofoca
- Formulário para enviar fofocas com título e texto
- Armazenamento das fofocas no navegador usando `localStorage`
- Tradução dos textos fixos para português, inglês e espanhol

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Explore o site — e fique de olho nos segredos.

## Um pequeno segredo

As fofocas enviadas ficam salvas apenas no navegador em que foram enviadas. Este projeto é uma criação independente, desenvolvida para fins de estudo, e não possui afiliação com a série de livros ou televisão *Gossip Girl*.
